# Overview

The Timer App is a productivity tool designed to help users manage both short-term and long-term tasks. It allows users to set, start, stop, and reset timers for different activities. Users can also track future goals with countdowns to important events.

## Features

- Short-term Timers: Users can create multiple timers for tasks such as working, taking breaks, and exercising.

- Long-term Countdown: Set and track long-term goals with countdowns to events like birthdays, project deadlines, and more.

- Edit and Delete Timers: Users can edit or remove timers from the list as needed.

- Audio Alerts: When a timer reaches zero, a sound is played to notify the user.

- Responsive Design: The app is fully responsive and works seamlessly on both desktop and mobile devices.

# Technologies Used

React: For building the user interface and handling state.

Vite: A modern build tool for fast development and efficient bundling.

CSS: For styling the application, ensuring a responsive and user-friendly design.

React Router: For navigation between different pages (like the main timer page and the long-term countdown).

JavaScript: For handling the app's logic, including timer countdowns and state management.

# Prerequisites
Node.js and npm must be installed on your system.

1. Clone this repository

2. Navigate into the project directory:
    cd timercards-phase-2-project

3. Install the dependencies:
    npm install
    npm install json-server

4. Start the development server:
    npm run dev

5. Start the mock API server:
    json-server db.json

6. Open the app in your browser:
    Visit http://localhost:3000 to start using the app.


# Usage

Short-term Timer:
    Set the hours, minutes, and seconds for a task.
    Click "Start" to begin the countdown.
    Use "Stop" to pause the timer, and "Reset" to reset it to the original time.

Long-term Countdown:
    Create long-term events with a target date and time.
    The app will display a countdown to the specified date.

Manage Timers:
    Edit the name and target time of a timer.
    Delete timers you no longer need.
